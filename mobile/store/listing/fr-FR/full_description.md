IMPORTANT — TEST FERMÉ EN MODE SIMULATION

Cette version de test démarre en Mode simulation et y reste. Ce n’est pas un défaut : c’est le cadre prévu pour les tests fermés.

Pourquoi c’est incontournable
• Vous n’avez pas besoin d’un colocataire, d’un partenaire ni d’un deuxième téléphone pour tester. Des participants simulés jouent le rôle des autres.
• Le but de ce test, c’est d’exercer Logement et Contacts en solo, sans dépendre de la disponibilité d’une autre personne réelle.
• Les modules Véhicule et Partage de véhicule sont désactivés ici. S’ils ne répondent pas : ce n’est pas un bogue — ils ne font pas partie de ce test.
• La sync réelle multi-appareils (relai) n’est pas l’objet de cette piste. Ne quittez pas le test en croyant qu’« il manque quelqu’un » : le Mode simulation est la façon prévue d’explorer.

À retenir avant d’écrire au support ou d’abandonner
• Ruban orange « Simulation » = vous êtes dans le mode de test solo.
• Parcours typique : créer / ouvrir un plan logement → participants → Mode simulation (déjà actif dans cette version) → explorer avec les participants simulés.
• Signalez les vrais problèmes sur Logement / Contacts / simulation. Ne signalez pas Véhicule / Partage comme « cassés ».

Bojairũ — la coloc, sans les embrouilles.

Qui paie le Wi‑Fi ? Les courses ? Le loyer ? Bojairũ aide les colocataires à tout gérer au même endroit : répartir les dépenses, se mettre d’accord sur les règles, suivre qui doit quoi — et aucun changement sans l’accord de tout le monde.

Vos données vous appartiennent. Pas de publicité. Pas de revente de données.

LOGEMENT (cœur de ce test)
• Construisez le plan avant de vous engager : dépenses récurrentes et ponctuelles, répartitions configurables, termes d’entente
• Proposez le plan ; chaque participant (y compris simulé) accepte, négocie ou refuse
• L’entente ne devient active que lorsque tous ont accepté la même révision
• Tenez le registre : dépenses, paiements, soldes automatiques, rappels et alertes de budget

CONTACTS (cœur de ce test)
• Une liste de personnes réutilisable dans les modules
• En Mode simulation : participants simulés pour tester sans invitation réelle
• Hors simulation (versions ultérieures) : connexion par code d’invitation — Bojairũ n’accède pas au répertoire du téléphone

VÉHICULE ET PARTAGE (hors périmètre de ce test)
Disponibles plus tard dans une version non limitée au Mode simulation. Dans cette version de test : désactivés volontairement.

VIE PRIVÉE
Bojairũ est local-first : vos ententes et comptes vivent d’abord sur votre appareil. Hors simulation, la synchronisation entre participants passe par un relais chiffré éphémère — sans cloud lisible de vos données personnelles. En Mode simulation, le travail reste sur l’appareil avec des participants simulés (pas de trafic relai réel entre humains).
